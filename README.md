# نظام إدارة المستخدمين وتسجيل الدخول (PHP + MySQL)

نظام متكامل، آمن وعصري لإدارة المستخدمين وتسجيل الدخول مبني باستخدام **PHP (PDO)** وقاعدة بيانات **MySQL**.

---

## 🌟 الميزات الرئيسية

1. **تسجيل الدخول وإدارة الجلسات (Authentication & Sessions)**:
   - تسجيل الدخول باستخدام اسم المستخدم أو البريد الإلكتروني.
   - حماية ضد هجمات تثبيت الجلسة (Session Fixation) عبر `session_regenerate_id()`.
   - كعكات جلسة آمنة (HttpOnly Cookies).
   - تسجيل الخروج وتدمير الجلسة بالكامل.

2. **إدارة المستخدمين بالكامل (CRUD)**:
   - **عرض المستخدمين**: جدول متجاوب وأنيق مع شريط بحث وتصفية فورية.
   - **إضافة مستخدم**: التحقق من البيانات وتفادي تكرار اسم المستخدم والبريد.
   - **تعديل مستخدم**: تعديل البيانات وتغيير الصلاحيات وتحديث كلمة المرور اختيارياً.
   - **حذف مستخدم**: تأكيد الحذف، حماية من حذف الحساب الشخصي المسجل به حالياً، ومنع حذف آخر مدير.

3. **الأمان (Security Best Practices)**:
   - تشفير كلمات المرور بأحدث معايير التشفير `password_hash()` و `PASSWORD_BCRYPT`.
   - استخدام استعلامات PDO المجهزة (Prepared Statements) لمنع هجمات SQL Injection.
   - حماية ضد هجمات Cross-Site Request Forgery (CSRF Tokens).
   - حماية ضد XSS عبر تنظيف المخرجات بدالة `htmlspecialchars()`.

4. **تصميم عصري وجذاب (Modern UI & UX)**:
   - واجهة عربية بالكامل (RTL) مع خط **Cairo** المتميز.
   - بطاقات إحصائية سريعة لعدد الحسابات والمدراء.
   - إشعارات وتنبيهات تفاعلية (Flash Messages).
   - تصميم متجاوب لجميع الشاشات والأجهزة.

---

## 🚀 طريقة التشغيل عبر XAMPP

1. تأكد من تشغيل خادمي **Apache** و **MySQL** من لوحة تحكم XAMPP Control Panel.
2. افتح المتصفح وتوجه إلى الرابط:
   ```
   http://localhost/test/login.php
   ```
   أو مباشرة:
   ```
   http://localhost/test/
   ```
3. **التهيئة التلقائية**:
   النظام يقوم تلقائياً بإنشاء قاعدة البيانات `user_management_db` والجدول والمستخدم الافتراضي عند أول زيارة دون الحاجة لأي إعدادات يدوية!

## 📁 هيكلية الملفات

- `config.php`: إعدادات الاتصال، إدارة الجلسات، ودوال الأمان والـ CSRF.
- `db.php`: الاتصال بقاعدة البيانات (PDO) والتهيئة التلقائية.
- `schema.sql`: ملف قاعدة البيانات للاستيراد اليدوي عبر phpMyAdmin إن رغبت.
- `login.php`: واجهة تسجيل الدخول.
- `logout.php`: معالج تسجيل الخروج.
- `index.php`: لوحة التحكم وعرض قائمة المستخدمين والإحصائيات والبحث.
- `user_add.php`: نموذج إضافة مستخدم جديد.
- `user_edit.php`: نموذج تعديل بيانات المستخدم.
- `user_delete.php`: معالج حذف المستخدم.
- `assets/css/style.css`: التصميم والتنسيقات المتجاوبة.
